# Security

## Scope

This repository is a synthetic governance demonstration, not a production authorization,
assessment, evidence, or recordkeeping system. Do not submit personal, confidential, employer,
client, regulated, security-sensitive, or other nonpublic information.

The application intentionally has no authentication, persistence, database, telemetry code,
external integrations, or secrets. Public deployment is suitable only for fictional and
synthetic demonstrations.

## Reporting a vulnerability

Do not include exploit details or sensitive information in a public issue. Use GitHub private
vulnerability reporting for this repository when available. Otherwise, contact the repository
owner privately through GitHub before disclosing details publicly.

Include the affected commit, reproducible steps using synthetic information, likely impact, and
any suggested mitigation. Do not test against systems, accounts, or data you do not own or have
explicit permission to assess.
